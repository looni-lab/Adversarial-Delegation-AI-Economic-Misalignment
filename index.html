The term

Adversarial delegation

We introduce adversarial delegation: when a user delegates a task to a personal AI agent and grants it access to personal context, the agent uses that context against the user's stated interest — here, pricing recommendations to the wealth it infers instead of following the request.

It is the first failure mode we catalog under AI economic misalignment: cases where an AI system's economic behavior diverges from the interests of the person it acts for.
